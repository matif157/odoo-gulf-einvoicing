Gulf E-Invoicing

ZATCA Phase 1 QR codes and UBL 2.1 XML for Odoo 19

Saudi Arabia requires a compliant QR code on every tax invoice and a UBL 2.1 document behind it. Odoo Community ships neither. This module adds both, with an audited record of every e-invoice generated.

  • ZATCA Phase 1 QR payload: 5-field TLV, base64
  • UBL 2.1 Invoice XML with ICV, PIH and per-line VAT
  • Standard (0100000) and simplified (0200000) invoice types
  • UUID, payload and XML stored on the invoice, logged in the chatter
  • Pure-Python compliance library with 37 tests that need no database
